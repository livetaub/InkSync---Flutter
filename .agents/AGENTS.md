# Project Rules

- Before implementing any major code changes or new features, provide a rundown/outline of the proposed changes in the chat for review and approval. Do not write or update the `implementation_plan.md` artifact.
- Focus the rundown on what we are going to do, explaining how the functionality, logic, and user flow will work.
- Do not open the browser to test changes yourself. Instead, ask the user to check manually and provide feedback.
